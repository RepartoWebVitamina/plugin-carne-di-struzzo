# Plugin Carne di Struzzo

Raccolta di plugin WordPress/WooCommerce custom. Ogni plugin vive nella propria cartella ed è installabile copiandola (o zippandola) in `wp-content/plugins/`.

| Plugin | Descrizione |
|---|---|
| [cds-liste-prelievo](cds-liste-prelievo/) | Liste di prelievo stampabili (per prodotto e per destinatario) dagli ordini selezionati |
